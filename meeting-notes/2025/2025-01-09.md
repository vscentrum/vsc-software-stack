## Software installations on Tier-1 @ VUB [Alex]

- will use Waldur for allocations/projects
    - VSC admins will get accounts on Waldur web interface to help manage allocations
    - stats of project usage (computer, disk) will be visible & manageable
- VSC admins will be able to do central software installations for users
    - bot will take care of actually installing the software
    - VSC-wide working group on tackling software installation requests
    - all software installed on Tier-1 should also be installed on all Tier-2 systems
- EESSI will be available as common software stack
    - custom software installations on top specific to Tier-1d
    - alongside typical central software stack
- figuring out managing of user installation requests
    - probably through a small dedicated web interface with form to submit requests
    - ticket will be created based on that (maybe Waldur, local ticket system at VSC sites, etc.)
- leave a lot of room to let users manage their own software
    - Python virtual environments, Apptainer, etc.
    - try to not waste time installing software that will not be used extensively
    - (Steven) maybe also tooling combining containers + Python envs, similar to what available for LUMI for Python packages?
- changes being made @ UGent to try and push down number of incoming requests
    - see https://docs.hpc.ugent.be/software_installation_requests/
    - requesting "software usage report" ~1 month after installing software
