## Tier-1 @ VUB - Software Installations

### 1. Guidelines for User Support
- VUB has seen that (mostly industry) "abuse" support service that is provided
    - requests on installations to match with how they typically use it
    - complaints about self-installed software with different versions, trouble is raised to support team
    - trying to "steal" our know-how (optimizations, etc.), using it on other systems (like for installations on LUMI)
- UGent has also makes some changes to software installation requests end of 2025
    - see https://www.ugent.be/hpc/en/support/software-installation-request + https://docs.hpc.ugent.be/software_installation_requests
    - "requiring" to submit software usage report
- plan of VUB is to have a clear policy of what's in scope for getting support
- try to encourage users to self-install stuff as much as possible
    - vsc-venv for Python, vsc-Rproject for R
    - also building own containers
- also planning to put a cap on free support (# hours)

### 2. Use of vsc-apps-bot

- main goal is to allow other VSC admins to get software installed Tier-1 @ VUB
- currently PoC (by Kenneth+Lara @ UGent and Sam @ VUB) is being done in private GitHub repo @ `vscentrum/vsc-apps-bot`
    - other VSC admins can get access to this
    - workflow to add software is to open a PR with easystack file that lists the easyconfigs to install
    - Sam is working on implementing 2-step approach: let bot build in staging location (via bwrap), and then have a separate explicit "deploy" step
        - requires some changes in EasyBuild, cfr. easyblock PRs by Sam

### 3. Have a way to let users provide easyconfigs to install centrally

- have an app where people can see what's already support in EasyBuild
    - only bot would need access `vsc-apps-bot` repo
    - maybe bot would need to be done in a container
    - ideally software already installed is exposed through this app
        - both in `/apps`, but also in EESSI
    - app should be stateless
    - request should be sent via email to `compute@vscentrum.be` for tracking
    - will not be open to the public, login via VSC account will be required
    - list of easyconfigs will be restricted to toolchains that are already installed
