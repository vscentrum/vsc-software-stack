## PyTorch

- Alex is working on support for installing PyTorch through binary wheels
    - see [PR #25267](https://github.com/easybuilders/easybuild-easyconfigs/pull/25267)
- PR for (from source) PyTorch 2.9.1 w/ `foss/2025b` + CUDA 12.9.1 [#24926](https://github.com/easybuilders/easybuild-easyconfigs/pull/24926)
- idea is to let sites pick which PyTorch installation they want
    - for most easyconfigs (that only depend on `import torch`) using either PyTorch dependency should work
        - stuff that links to `libtorch.so` would probably require two separate easyconfigs
- [open PR #4217 for PyTorch easyblock](https://github.com/easybuilders/easybuild-easyblocks/pull/4217) to fix oversubscribing of cores when running test suite
