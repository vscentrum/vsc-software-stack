If you hard-pin yourself to (a) dask==2024.9.1 and (b) cuda-python==12.6.2.post1, then the “natural” RAPIDS/rapids-singlecell combination is the RAPIDS 24.10 line, and therefore rapids-singlecell 0.10.11 (or nearby 0.10.x), because that’s the rapids-singlecell release that explicitly pins RAPIDS to 24.10.* in its extras.

The catch: RAPIDS pins Dask too tightly

RAPIDS doesn’t just “support some Dask range”; it uses rapids-dask-dependency to pin exact versions. For RAPIDS 24.10, rapids-dask-dependency==24.10.* requires:

dask==2024.9.0

distributed==2024.9.0

dask-expr==1.1.14

So there is no RAPIDS 24.10 configuration that is strictly satisfied by dask==2024.9.1 without either:

also providing dask==2024.9.0 somewhere in the environment (e.g., inside the rapids-singlecell prefix so pip check is happy), or

patching metadata (loosening the ==2024.9.0 pin), or

disabling/avoiding the RAPIDS components that depend on rapids-dask-dependency (but cugraph-cu12 and cuml-cu12 pull it in at 24.10).

In practice, the “least ugly EB way” is usually: ship a local dask==2024.9.0 + distributed==2024.9.0 + dask-expr==1.1.14 as extensions inside the rapids-singlecell install (so you can keep your site-wide dask/2024.9.1 module untouched, but pip check + runtime import expectations are met for RAPIDS 24.10).

What rapids-singlecell version fits best under your constraints?

Answer: rapids_singlecell==0.10.11 (RAPIDS 24.10.* via rapids12 extra).

0.10.11 has:

rapids12 = ["cupy-cuda12x", "cudf-cu12==24.10.*", "cuml-cu12==24.10.*", "cugraph-cu12==24.10.*"]

That matches your “keep CUDA 12” intent and aligns with the Dask pinning era you’re trying to stay in (2024.x Dask), unlike rapids-singlecell 0.14.1 which pulls RAPIDS 26.2 and consequently drags in much newer Dask in practice.

Where cuda-python==12.6.2.post1 fits

For RAPIDS 24.10, cuml-cu12 doesn’t even list cuda-python in its runtime requirements (it’s mostly pulling NVIDIA CUDA component wheels + other RAPIDS packages).
So keeping cuda-python==12.6.2.post1 is not the main blocker in the 24.10 stack—the Dask exact-pin is.
